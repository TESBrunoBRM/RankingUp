- Vista de alimentos: cantidades con coma decimal coherentes en la vista previa y al guardar; mensaje de error recibido del servidor visible al usuario.

Estos cambios de interfaz todavía requieren una nueva build. No se generó un APK ni se publicó el código nuevo de la API en esta intervención. Los dos errores de base de datos ya se resolvieron para la API y los APK existentes.
